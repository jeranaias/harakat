Add to Your Project

أضفه لمشروعك

Three lines of code to add Arabic diacritization to any Python project.

ثلاثة أسطر لإضافة التشكيل العربي لأي مشروع Python.

Live Python REPL demonstration عرض مباشر في Python REPL

diacritize.py 
from harakat import diacritize

# Single text
text = "ذهب الولد الى المدرسة"
result = diacritize(text)
print(result)
# Output: ذَهَبَ الْوَلَدُ إِلَى الْمَدْرَسَةِ

# Batch processing
texts = ["السلام عليكم", "كيف حالك", "الحمد لله"]
results = [diacritize(t) for t in texts]
terminal الطرفية 
# Install
$ git clone https://github.com/jeranaias/harakat.git
$ cd harakat
$ pip install -r requirements.txt

# Run on text
$ python harakat.py "مرحبا بالعالم"
مَرْحَبًا بِالْعَالَمِ

# Run on file
$ python harakat.py --file input.txt --output diacritized.txt
api_example.js مثال_api.js 
// Call the Harakat API (Gradio format)
const API = 'https://jcmguy-harakat.hf.space';

// Step 1: Submit request
const call = await fetch(API + '/call/predict', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ data: ['مرحبا بالعالم'] })
});
const { event_id } = await call.json();

// Step 2: Get result
const result = await fetch(API + '/call/predict/' + event_id);
const text = await result.text();
// Parse SSE: data: ["مَرْحَبًا بِالْعَالَمِ"]
